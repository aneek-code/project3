# 🎮 NEXUS — Game Discovery Website

A fictional gaming news and discovery website built with HTML and CSS.

NEXUS was created as a CSS learning project focused on responsive layouts, CSS Grid, Flexbox, media queries, typography, and modern website structure.

---

## 📌 About the Project

NEXUS is a fictional gaming platform designed to present gaming news, featured games, articles, and highly-rated games in a modern gaming-focused interface.

The project was created as part of my journey of learning HTML and CSS. The main goal was not to create a fully functional gaming platform, but to experiment with layouts and responsive design using only HTML and CSS.

## 📱 Responsive Design

One of the main goals of NEXUS was to experiment with responsive design.

The layout changes at different screen widths using CSS media queries.

### Desktop

The website uses multi-column layouts for:

- Navigation
- Featured content
- Game cards
- Top-rated games
- Footer sections

### Smaller Screens

The layouts are rearranged into fewer columns or single-column sections to make the content easier to view on smaller screens.

The navigation was also adapted using CSS without JavaScript.
